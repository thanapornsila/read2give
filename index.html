How to Deploy & Use This Code

Option 1: Free Hosting on GitHub Pages (Recommended)

  1. Create a free repository named read2give-prototype on GitHub.
  2. Save this file as index.html and upload it.
  3. Go to Settings -> Pages and enable GitHub Pages.
  4. Your live web prototype link is ready to share for user testing!

Option 2: Deploy on Netlify or Vercel

Simply drag and drop the folder containing index.html into Netlify Drop to get an instant live website URL.

Option 3: Run Locally on Computer

Save the code as index.html on your desktop, and double click to open directly in Chrome, Safari, or Edge!
